# Static site

A one-page personal or business site: a header, an intro, an about section, three project cards and a contact line. Plain HTML and CSS. No build step, no dependencies. The files are served as they are.

Runs on [CMO Studio](https://studio.cmopartners.co/?ref=template-static-site).

## Files

- `index.html`: the page. Replace the placeholder text.
- `styles.css`: the look. Colours are at the top, in `:root`.

## Environment variables

None.

## Run locally

Open `index.html` in a browser, or run `python3 -m http.server` in this folder.

## Change it with your AI agent

- "Rewrite the text for my photography business in Bergen and add a gallery section."
- "Change the colours to dark green and cream, and add a link to my Instagram."
- "Add an English and a Norwegian version of the page with a language link."
